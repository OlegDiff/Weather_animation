# Карта Европы — 18 октября 2026

Источник композиции: пользовательский файл `Europe Typographic City Map.png`, копия хранится в `docs/reference/`.
Названия, положение и относительные размеры букв перенесены вручную в `backend/map-layout.json`.
Это анимируемый текст на Canvas, а не растровая подложка: погодные эффекты воздействуют на буквы.

## Две версии

- Демо: http://127.0.0.1:8000/?mode=demo — синтетические сцены, первая со снегом во всех городах, затем смешанные эффекты. Переключение каждые 12 секунд, пауза и ручная смена сцены.
- Актуальная: http://127.0.0.1:8000/?mode=live — текущие модельные данные Open-Meteo; без подмены недоступных данных демосценами.
- Прежняя карта: http://127.0.0.1:8000/legacy/ — сохранены четыре города, включая Raris и Helsinki, исходные эффекты и управление.

Canvas имеет размер 1600 × 900, строго 16:9; масштабируется с сохранением пропорций.
Панель управления находится за пределами карты. На небольшом экране вся композиция уменьшается; для чтения мелких городов используйте большой экран или масштаб браузера. Наведение на подпись показывает название и эффект.

## Города и неоднозначности

Включены 175 однозначно распознанных городов исходной карты, включая небольшие подписи. Helsinki отсутствует на референсе и остаётся только в старой версии. На новой карте используется Paris, как на изображении.

Неразборчивая подпись под Mannheim не включена: название не выдумывалось. Две похожие подписи Iași на исходнике сведены к одному городу Iași. Для уточнения этих мест требуется подтверждение пользователя.

Координаты получены из [геокодирования Open-Meteo](https://open-meteo.com/en/docs/geocoding-api), основанного на GeoNames. Результаты с идентификаторами, страной и координатами хранятся в `backend/map-geocoding.json`.
Для Гомеля выбран город Homyel (GeoNames 627907), а не одноимённый посёлок; для Salamanca — город (3111108), а не район Madrid.
Различия написания на карте и у поставщика отделены: `name` — подпись, `query` — поисковое название, `id` — стабильный ключ с кодом страны.

После правки каталога пересоберите файл для браузера:

```powershell
python tools/build_city_map.py
```

## Получение погоды

`GET /api/weather?map=europe` (или без параметра) возвращает 175 городов.
`GET /api/weather?map=legacy` возвращает прежние четыре города.

Обновление отправляет до пяти параллельных запросов, каждый содержит не более 40 координат. Порядок ответа и близость координат проверяются. Сбой одной группы не обнуляет остальные. Кеш на 10 минут и повтор через минуту при сбое работают отдельно для городов. При отсутствии данных — neutral с unavailable; старые данные маркируются stale. Статус и время видны в раскрываемых блоках.

Радиусы, число частиц, облака и изгиб адаптированы к размерам маленьких надписей. Правила погоды прежние: снег → дождь → ветер от 5 м/с → пасмурно при облачности > 60% / солнце днём при облачности ≤ 60% → neutral.

## Проверки

- 69 тестов прошли с `WEATHER_BROWSER_TESTS=1`: старые сценарии, каталог, пакетная загрузка и частичный сбой, 175 подписей, снег в первой сцене, сопоставление реальной погоды по id, обе ссылки и пропорции 16:9 на широком и узком экране.
- Выполнен живой запрос Open-Meteo: все 175 городов вернули fresh. Это проверка доступности на момент запуска.
- Скриншоты браузерных тестов используют синтетические ответы и находятся в игнорируемой `.pytest_cache/`; они не являются снимками фактической погоды.
